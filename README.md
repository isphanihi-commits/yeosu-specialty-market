# 채소 시장

온라인 동시 접속(2~8명)용 6라운드 수요·공급 보드게임 프로토타입입니다.

## 실행

Node.js 18 이상에서 아래를 실행합니다.

```powershell
npm install
npm start
```

그런 다음 `http://localhost:3000`을 엽니다. 다른 사람이 접속하려면 이 앱을 인터넷에 배포한 뒤 같은 방 코드를 공유하면 됩니다.

## 규칙 구현

- 매 라운드 플레이어 수 + 1장의 카드가 열립니다.
- 시작 플레이어는 매 라운드 한 명씩 순환합니다.
- 남은 마지막 카드의 채소는 그 수량만큼 가격이 하락합니다.
- 마지막 카드에 없는 모든 채소는 1골드 상승합니다.
- 가격 범위는 0~10골드이며, 6라운드 후 보유 채소 수량 × 최종 시세로 승자를 정합니다. 동점은 공동 우승입니다.
